# 遷移對照：kitJoin、kitsUI → kitDesign

[English](en/migration.md) | 繁體中文

kitJoin 0.5.0 與 kitsUI 0.4.0 改用 kitDesign 0.1.0 時，照這張表把舊的名字換成新的。
kitDesign **不匯出舊名字的別名**：換完以後，app 裡不應該再有這些函式的定義。

換的步驟（每個 app 一次）：

1. DESCRIPTION 加 `Imports: kitDesign (>= 0.1.0)`、`Remotes: jiewenTsai/kitDesign@v0.1.0`。
2. 照下表換名字（多半是一對一的取代）；「參數不同」一欄要另外看。
3. 刪掉 app 裡的 `R/kit_brite.R`、`R/kit_theme.R` 的樣式函式、`R/code_wrap.R`，以及下表「刪掉」的函式。
4. 頁面改用 `kit_page()`（不再需要 `tags$head(tags$style(kit_css()))`、`kit_app_js()`、`kit_tabs_js()`、`kit_js()`）。
5. 跑 app 自己的測試；用 `tools/check_gallery.R` 同樣的方法截圖，對照改之前的畫面。
6. 重新產生 `manifest.json`。

## kitsUI 名字不一樣的

| kitsUI 0.4.0 | kitDesign 0.1.0 | 參數不同 |
|---|---|---|
| `mod_guide(goal, steps, output, note)` | `kit_tab_guide(goal, steps, output, technical = NULL, note = NULL, diagram = NULL)` | `steps` 可以直接給字串向量（和以前一樣）；`note` 要寫名字 |
| `ui_status(kind, line, ..., points)` | `kit_status_ui(kit_status(state, message, points = ))`，或直接放 `kit_status()` 物件 | `kind` 的 done／warn／stop／stale 仍然接受（會換成 success／warning／error／stale）；`...` 放進 `kit_status_ui(st, ...)`；「還有 N 點」的 class 從 `kit-status-notes` 改成 `kit-status-more`（見下面「看得到的差別」） |
| `ui_status_points(points)` | `kit_status_ui()` 內建 | 刪掉 |
| `ui_raw_text(raw, title)` | `kit_status(details = raw, details_title = title)` | 原文改成狀態框的欄位 |
| `ui_button(id, label, kind)` | `kit_button(id, label, kind)` | 一樣 |
| `ui_callout(..., warning = TRUE)` | `kit_callout(..., warn = TRUE)` | `warning` → `warn`；class 從 `kit-callout-warning` 變成 `kit-callout-warn`（兩個 class 的樣式一樣） |
| `ui_warn_list(head, items)` | `kit_callout(strong(head), tags$ul(...), warn = TRUE)` | 刪掉（只是組合） |
| `ui_next_step(text, button_id, label, kind)` | `kit_next_step(text, button_id, label, kind = "primary")` | 一樣；說明從 `<p class="kit-hint">` 變成 `<div class="kit-hint">` |
| `ui_advanced(..., title, open)` | `kit_advanced(..., title, open, id = NULL)` | 一樣 |
| `ui_details_row(...)` | `kit_details_row(...)` | 一樣 |
| `ui_detail(title, ..., open)` | `kit_detail(title, ..., open)` | 一樣 |
| `ui_settings_line(text)` | `kit_settings_line(text, prefix = NULL)` | 要加 `prefix = NULL`（kitJoin 的預設前綴是「本次：」） |
| `ui_code_panel(id, title)` ＋ `render_code_panel(session, id, code)` | `kit_code_panel_ui(id, title)` ＋ `kit_code_panel_server(id, code)`（模組）；或 `kit_code_panel(output_id)` ＋ `kit_render_code_panel(code)` | 程式碼不再用 `verbatimTextOutput()`，改成 `kit_code()`；版本名稱用具名 list：`list("kits 版" = code)` |
| `ui_code_block(id, label)` | `kit_code(code, label)` | 刪掉 |
| `KIT_CODE_LABEL`、`KIT_CODE_EMPTY` | `kit_code(label = "kits 版")`、`kit_render_code_panel(empty = )` | 刪掉 |
| `kit_tabs_js()` ＋ `kit_tab_state` 訊息 ＋ `kit_tab_message()` | `kit_step_tabs_ui()`／`kit_step_tabs_server()`（模組）；或 `kit_flow_tabs()` ＋ `kit_tab_states()` ＋ `kit_watch_tab_states()` | 狀態用同一套名字：done／locked／stale／ready；原因（`why`）改叫 `tip` |
| `kit_tab_states(data_ok, items, link_done, score)` | 留在 kitsUI（app 自己的規則），最後交給 `kit_tab_states(states, locked, locked_tips, tabset)` | 改成回傳每個分頁的狀態 |
| `#tabs a[data-value='manual']` 的 CSS（`kit_css()`） | `kit_flow_tabs(..., aside = "manual")` | 刪掉 CSS |
| `kit_js()`（`kit_unload_guard` 訊息） | `kit_unload_guard(on)` | 訊息名稱改成 `kit-unload-guard` |
| `KIT_CHART_COLORS`、`KIT_CHART_NEUTRAL`、`kit_chart_colors(n)` | `kit_chart_colors(n)`、`kit_chart_neutral()` | 一樣 |
| `kit_chart_role()`、`kit_chart_categorical()`、`kit_chart_zh()` | 留在 kitsUI | kits 與 plotly 專用 |
| `kit_header()` 版本行的「kits 0.25.0」 | `kit_page(meta_extra = paste("kits", packageVersion("kits")))` | |
| `kit_app_description()`（只找 kitsUI） | `kit_app_description("kitsUI")` | 要給套件名稱 |

## kitJoin 名字不一樣的

| kitJoin 0.5.0 | kitDesign 0.1.0 | 參數不同 |
|---|---|---|
| `make_status_ui(st)` | `kit_status_ui(st)`，或直接放 `kit_status()` 物件 | 一樣 |
| `format_dims(nrow, ncol, preview_cols)` | `kit_dims(nrow, ncol, preview_cols)` | 一樣 |
| `kitsdata_check(state, title, text, actions)` | `kit_check(state, title, why, actions)` | `text` → `why` |
| `tags$ul(class = "kit-checklist", ...)` | `kit_checklist(...)` | |
| 步驟卡的 `head_ui()`（mod_kitsdata.R） | `kit_step_head()`；整組用 `kit_stepcards_ui()`／`kit_stepcards_server()` | |
| `tags$div(class = "kit-problems", ...)` | `kit_problems(..., head = "還差：")` | |
| `kit_navgroups(tabset, selected)` ＋ `KIT_TAB_GROUPS` | `kit_navgroups(groups, tabset, selected)` ＋ `kit_navgroup()`；或模組 `kit_step_tabs_ui(..., groups = )` | 分組改成參數 |
| `kit_tab_states(n_files, states, tabset)` | 留在 kitJoin（規則是 app 的），最後交給 `kit_tab_states(status, locked, locked_tips, tabset)` | |
| `kit_run_gate(session, output, missing, link, button_id)` | 一樣；或模組 `kit_run_gate_ui()`／`kit_run_gate_server()` | 多了 `output_id` |
| `kit_code_blocks(snips)` | `kit_code_blocks(snips, note = )` | 預設說明改成通用的那一句；kitJoin 原本的說明用 `note = ` 傳 |
| `kit_abort_class(class, ..., data)` | `kit_abort(..., class = , data = )` | 參數順序不同 |
| `kit_app_meta()`（讀 DESCRIPTION） | `kit_app_meta(version, date, extra, show_kitdesign)` | 版本要傳進去 |
| `kit_header(title, subtitle, tagline, meta)` | `kit_header(title, subtitle, tagline, version, date, meta_extra, logo, show_kitdesign)` | `meta` → `version`、`date` |
| `kit_kitsui_link()`、`kit_kitsui_button()` | 留在 kitJoin；裡面的連結可以用 `kit_app_link()` | |
| `KIT_BTN[["secondary"]]` | `kit_btn_class("secondary")` | |
| `kit_css()`、`kit_css_guide()`、`kit_css_brite()`、`kit_app_js()` | `use_kit()`（`kit_page()` 已經放了） | 刪掉 |
| `kit_code_cols()`、`kit_code_wrap()`（code_wrap.R） | 一樣（從 kitJoin 搬過來） | 刪掉 app 的那一份 |

## kitDesign 0.4.0：下載與雲端版搬進 kitDesign

kitJoin 0.6.0、kitsUI 0.5.0 改用 `Imports: kitDesign (>= 0.4.0)`；刪掉兩個 app 的 `R/download.R`，
`R/cloud.R` 只留文字。

| app 裡的 | kitDesign 0.4.0 | 參數不同 |
|---|---|---|
| `kit_download_button(session, id, label, filename, content, class)` | `kit_download_button(..., app = )` | 多了 `app`（預設 `getOption("kitDesign.app", "kit")`）；app 在 `.onLoad()` 設 `options(kitDesign.app = "kitJoin")` |
| `kit_download_type()` | 內部 | 用 kitsUI 的版本：`.csv`、`.zip`、`.html` 有自己的 MIME，其他（`.sav`、`.csv.gz`）是 octet-stream |
| `kit_ascii_filename()`、`kit_content_disposition()`、`kit_download_ext()`、`kit_percent_encode()`、`kit_register_download()`、`kit_download_filter()`… | 內部 | 備用檔名的「kitjoin」「kitsui」改成 `tolower(app)` |
| 測試的 `kit_test_download(session, id)`（helper-download.R） | `kit_test_download(session, id, write = TRUE)` | 回傳多一個 `filename`；`write = FALSE` 只看檔名 |
| `kit_is_cloud()` | `kit_is_cloud()` | 一樣 |
| `kit_cloud_footer()`（文字寫在函式裡） | `kit_cloud_footer(sections, links, title, id)` | 文字變成參數：`sections` 是「段名 = 內文」，`links` 是「連結的字 = 網址」；app 留 `kitjoin_cloud_footer()`、`kitsui_cloud_footer()` |

kitJoin 每個分頁重複的骨架換成 `kit_run_tab_ui()`／`kit_run_tab_server()`：

| kitJoin 分頁裡的 | `kit_run_tab_*` |
|---|---|
| `uiOutput(ns("settings_line"))`、`uiOutput(ns("ready"))`、`kit_button(ns("run"), …, disabled = TRUE)`、`uiOutput(ns("status"))`、`kit_download_ui(ns)`、`kit_details_row(uiOutput(ns("result_details")), kit_code_panel(ns("code")))` | `kit_run_tab_ui(id, run_label, guide, ..., result, downloads, details, code, next_step)` |
| `kit_run_gate(session, output, missing, link)` | `ready = `、`ready_link = ` |
| `output$settings_line <- renderUI(kit_settings_line(c(…)))` | `settings = function() c(…)` |
| `observeEvent(list(…), { if (!is.null(result())) { result(NULL); status(kit_stale_status(…)) } })` | `stale_on = function() list(…)` |
| `observeEvent(input$run, { result(NULL); st <- tryCatch(withProgress(…), error = …); status(st); kit_notify(st); kit_scroll_to("status") })` | `run = `、`done = `、`error = `、`progress = `（還沒按以前的檢查 `guard = `，要確認的錯誤 `confirm = `） |
| `output$status <- renderUI(kit_status_ui(status()))` | 內建 |
| `output$result`、`output$result_details` 的 `if (is.null(res)) return(NULL)` | `result_ui = function(res)`、`details_ui = function(res)` |
| `output$code <- renderUI(kit_code_blocks(…, note = ))` | `code = function() …`、`code_note = ` |
| `list(state = reactive(status()$state))` | `list(state = tab$state)` |

app 自己的下載區（kitJoin 的 `kit_download_server()`：CSV、CSV.GZ、SAV 三顆鈕與 SPSS 改名提醒；
kitsUI 的 `download_csv_ui()`、`download_plot_ui()`：readr 的 CSV、要 pandoc 的圖檔）留在 app：
寫檔的格式是 app 的。

## 留在 app 裡的（不搬）

- kits、IRT、檔案讀寫：`read_data_file`、SAV/CSV 的讀寫、`kitsui_*`、`kits_*`、`check_table`、`kit_table`（kitsUI 的計數欄規則）……
- 下載區：kitJoin 的 `kit_download_server()`、`kit_download_ui()`，kitsUI 的 `download_*_ui`、`render_download_*`（寫檔的格式是 app 的；按鈕本身是 kitDesign 的 `kit_download_button()`）。
- 使用手冊與 pandoc：`kit_manual_ui`、`kit_pandoc_*`、`kit_setup_pandoc`。
- 兩個 app 之間的連結：`kit_kitsui_link`、`ui_kitjoin_button`、`ui_kitjoin_hint`、`KITSUI_URL`、`KITJOIN_URL`。
- 雲端版的文字：橫幅的一句話、使用須知的每一段（`kitjoin_cloud_footer()`、`kitsui_cloud_footer()`）。
- 其他 app 專用的：`kit_source_note_ui`、`kit_upload_todo`、`join_method_example`、`kit_max_upload_mb`、`ui_go_items`。

## 看得到的差別（遷移後要對照截圖）

- 危險按鈕（`kind = "danger"`）：kitDesign 0.2.0 起是鮭紅色（`nb-salmon`）、黑字，照設計語言；兩個 app 以前是 Bootstrap 的紅色。
- 分頁上看不見的「（已完成）」：放在分頁列裡（分頁列與分頁是定位的基準），手機上不會把整頁撐寬。
- kitJoin 的題目表樣式（`.kit-itemtable`）搬進 kitDesign，app 不用另外寫 CSS。
- kitsUI 的「還有 N 點」：以前是 `details.kit-status-notes`（小一號的字），改成 kitJoin 的 `details.kit-status-more`（和其他點一樣大）。
- kitsUI 的流程分頁做完時多了一個看不見的「（已完成）」，看得到的 ✓ 一樣。
- kitsUI 的「用 R 怎麼做」：程式碼從 `verbatimTextOutput()` 換成 `kit_code()`（同樣的框；長的行會自動換行）。
- 「複製」按鈕：`onclick` 改成 `kit.js` 處理（`.kit-copy`），樣子一樣。
